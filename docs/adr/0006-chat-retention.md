# Raw chat is kept for 30 days

Roomie reads every message in every Chat it's in, including messages nobody meant for it. Raw message text is kept for 30 days, which is enough for context and for building the Group style. After that, only the Group style, Member notes and Roomie's own memory summaries remain. "roomie forget me" deletes a Member's raw messages and Member note, and an Admin can delete all of a Group's data from the dashboard.
